# Wirkung

| Stufe | Wirkung                                                                                                                                                                                                           |
| :---: | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|   A   | Ziel erhält 2W6 - 2 Heilpunkte, für jede Überschreitung der WS wird eine Wunde geheilt, erleidet jedoch eine leichte Sinnestrübung (Proben mit KL FF/GE -2  für 1 Stunde).                                        |
|   B   | Ziel erhält 2W6 Heilpunkte.                                                                                                                                                                                       |
|   C   | Ziel erhält 2W6 + 4 Heilpunkte.<br>Kampfunfähigkeit und Blutungen werden geheilt.                                                                                                                                 |
|   D   | Ziel erhält 3W6 + 6 Heilpunkte.<br>Kampfunfähigkeit und Blutungen werden geheilt.                                                                                                                                 |
|   E   | Ziel erhält 4W6 + 8 Heilpunkte. Auch über das Maximum heraus.<br>Kampfunfähigkeit und Blutungen werden geheilt.                                                                                                   |
|   F   | Alle Wunden oder Erschöpfung werden geheilt.<br>Neutralisiert die Wirkung aller Tränke, Gifte und Elixiere für eine Woche (also auch alle weiteren Heiltränke).<br>Kampfunfähigkeit und Blutungen werden geheilt. |
