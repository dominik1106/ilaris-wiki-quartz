# Wirkung

Angewendet auf eine metallene Waffe:

| Stufe | Wirkung                                                                                                                               |
| :---: | ------------------------------------------------------------------------------------------------------------------------------------- |
|   A   | Für 1 Tag: Härte +2                                                                                                                   |
|   B   | Für 1 Tag: Härte +2, +1 TP                                                                                                            |
|   C   | Für 1 Tag: Härte +2, +1 TP, Waffe gilt als magisch                                                                                    |
|   D   | Für 1 Tag: Härte +4, +2 TP, Waffe gilt als magisch                                                                                    |
|   E   | Für 1 Woche: Waffe ist außer durch Magie so gut wie unzerbrechlich, Härte +8, +3 TP, Waffe gilt als magisch                           |
|   F   | Die Waffe gilt als magisch, wird tatsächlich unzerbrechlich, +4 TP, leuchtet in grellem weißen Feuer, zerfällt nach 1 Stunde zu Staub |
