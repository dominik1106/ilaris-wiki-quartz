- **Preis**: 60 D / Stück
- **Haltbarkeit**: 4 Jahre

# Wirkung

| Stufe | Wirkung                                                                                                                                                             |
| :---: | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|   A   | Das Ziel regeneriert sofort 1W6 AsP, erleidet jedoch eine leichte Geistesverwirrung (Proben mit KL -2 für 1 Stunde).                                                |
|   B   | Das Ziel regeneriert sofort 2W6 - 2 AsP, die er jedoch innerhalb der nächsten Stunde verbrauchen muss, ansonsten drohen ihm starke Kopfschmerzen (-4 für 8 Stunden) |
|   C   | Das Ziel regeneriert sofort 2W6 AsP                                                                                                                                 |
|   D   | Das Ziel regeneriert sofort 2W6 + 4 AsP, auch über das Maximum, jedoch verursachen Punkte über das Maximum Schadenspunkte.                                          |
|   E   | Das Ziel regeneriert sofort 3W6 + 6 AsP, mit Nebeneffekt.                                                                                                           |
|   F   | Das Ziel regeneriert sofort 1W20 + 8 AsP, ohne Nebeneffekt übers Maximum                                                                                            |
